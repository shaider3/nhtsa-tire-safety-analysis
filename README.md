# nhtsa-tire-safety-analysis

# Assignment 3: Functional Programming in R

This project implements functions for data manipulation and analysis using functional programming principles in R. 
The project is also expanding to integrate real-time and historical environmental data using a Weather API. By cross-referencing crash timestamps and geographical locations with weather metrics (such as rainfall, snow, and freezing road conditions), I aim to evaluate what tires can lead to a disproportionately higher rate of vehicle loss-of-control during adverse weather events.

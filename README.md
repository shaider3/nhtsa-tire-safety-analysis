# nhtsa-tire-safety-analysis

# Assignment 3: Functional Programming in R

This project implements functions for data manipulation and analysis using functional programming principles in R. 
The project is expanding to integrate real-time and historical environmental data using the **Weatherstack API** and **Open-Meteo Historical Weather API**. By cross-referencing crash timestamps and geographical locations with weather metrics (such as rainfall, snow, and freezing road conditions), we aim to evaluate whether low tread depths ($\le 3/32"$) lead to a disproportionately higher rate of vehicle loss-of-control during adverse weather events.

## Included Files

- `assignment3.R` – R script containing the implementation of all required functions.
- `assignment3.html` – Rendered HTML report containing code execution, output, and analysis.
